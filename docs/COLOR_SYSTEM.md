# MilestoneX Color System

MilestoneX uses a monochromatic green identity with neutral light/dark surfaces. Pink, coral, orange, yellow, blue, and purple are not part of normal product UI.

## Brand greens

| Token | Hex | Use |
|---|---|---|
| Accessible green | `#147A4F` | Light-theme labels, links, focused controls |
| Emerald | `#2FD48A` | Decorative route and hero highlights |
| Bright mint | `#55E2A4` | Diagram arrows and proof accents |
| Dark-theme accent | `#63E2AA` | Dark-theme labels, links, active controls |
| Soft mint | `#72E8B1` | Gradients and decorative highlights |
| Pale mint | `#9AF2C9` | Logo arrow, high-contrast highlights |

## Light theme

| Token | Hex | Use |
|---|---|---|
| Page | `#F4F8F5` | Main background |
| Surface | `#FFFFFF` | Cards and dialogs |
| Secondary surface | `#F8FBF9` | Inputs and nested panels |
| Tertiary surface | `#EDF6F1` | Chips and soft emphasis |
| Primary text | `#0A1C14` | Headings and body |
| Muted text | `#5D7066` | Supporting copy |
| Border | `#D3E0D9` | Standard separators |
| Strong border | `#B9CEC3` | Focus and elevated structure |

## Neutral visual materials

The original hero artwork also uses:

- Pearl white
- Silver and transparent glass
- Charcoal
- Black
- Forest, emerald, jade, and mint greens

## Contrast checks

| Pair | Contrast ratio |
|---|---:|
| Light primary text on light page | `16.48:1` |
| Light muted text on light page | `4.93:1` |
| Dark primary text on dark page | `18.08:1` |
| Dark muted text on dark page | `7.70:1` |
| Dark button text on dark-theme mint CTA | `11.95:1` |
| Light-theme green text (`#147A4F`) on white | `5.35:1` |

## Semantic exceptions

Red is reserved only for a genuine error or failed transaction. It is not used as a decorative product color. Warning and pending states use green plus neutral text to preserve the monochromatic identity.
