## MilestoneX hero visual

`web/public/visuals/milestonex-hero.webp` is an original AI-assisted visual produced specifically for MilestoneX. It depicts an abstract escrow vault, a token path, and milestone nodes. The final visual uses only forest green, emerald, mint, pearl white, silver, charcoal, and black. It contains no third-party logo or text.

## Interface inspiration

The MilestoneX visual system takes high-level inspiration from Flare's public website—large editorial typography, black/white contrast, modular product storytelling, and abstract 3D forms—while using original layout, code, illustration, interaction design, logo, copy, symbols, and components.
